LexNote（利用規約改定版）静的サイト一式

収録ファイル
- index.html : トップページ（重要告知・プラン案内）
- revision.html : 規約改定のお知らせ・新旧対照表
- terms.html : 改定後の利用規約（全14条）
- styles.css : 共通デザイン・レスポンシブスタイル
- script.js : モバイルナビゲーション・同意UI

すべて同一フォルダに配置し、index.htmlを開いてください。
GitHub Pagesでは、このフォルダ内のファイル一式を公開先ディレクトリに配置してください。
ページ・CSS・JavaScriptの参照は相対パスで指定しており、サブディレクトリ公開に対応しています。
