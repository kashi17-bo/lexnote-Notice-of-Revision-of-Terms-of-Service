ファイル

- revision.html : 利用規約改定のお知らせ・新旧対照表

公開方法
1. 5ファイルを同じディレクトリに配置します。
2. GitHub Pages等の公開対象ブランチ／フォルダにアップロードします。
3. index.html を入口として公開します。

相対パスのみを使用し、ビルド工程・外部ライブラリは不要です。
